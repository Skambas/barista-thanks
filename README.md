# ☕ Налий собі кави

Сторінка подяки для баристи. Гість сканує QR-код на стійці, «наливає» каву в міні-грі, отримує випадкову подяку на листочку і за бажанням лишає чайові або ділиться листочком у сторіз. Інтерфейс українською.

Без акаунтів, без трекінгу, без cookie-банера. Чайові лише посилання на банку Monobank: гроші проходять повз цей сервіс.

## Як це працює

```
QR на стійці → сторінка → міні-гра (потримай склянку) → листочок з подякою
                                   ↓                            ↓
                              «Пропустити»         ☕ Лишити чайові · Поділитись у сторіз
                                                         · Ще одна · Налити ще раз
```

- **Фронтенд:** vanilla JS (ES-модулі) і CSS, збирається Vite. Шрифти Caveat і Lora self-host (woff2), без Google Fonts.
- **Бекенд:** один процес Node.js (Fastify). Віддає зібраний фронтенд, `GET /api/phrases` і `/healthz`.
- **Фрази:** SQLite у Docker-томі. Стартові фрази імпортуються з `src/phrases.json` один раз, на першому запуску.
- **Telegram-бот** (grammY, long polling) у тому ж процесі: фрази додаються й вимикаються з телефона, без перезбирання образу. Публічний webhook не потрібен.
- Якщо API недоступне, сторінка працює з вбудованими фразами.

## Швидкий старт (локально)

Потрібен Node.js 20.12 або новіший (у Docker-образі Node 22).

```bash
git clone https://github.com/Skambas/barista-thanks.git
cd barista-thanks
npm install
cp .env.example .env      # Windows PowerShell: Copy-Item .env.example .env
```

Відкрий `.env` і заповни хоча б `MONOBANK_JAR_URL` та `SITE_URL`.

**Повний стек, як у продакшені:**

```bash
npm run build
npm start
```

Сторінка на <http://localhost:3000>.

**Розробка фронтенду** (гаряче перезавантаження), у двох терміналах:

```bash
npm run dev:server    # API і база на :3000
npm run dev           # Vite на :5173, запити /api проксуються на :3000
```

У режимі `npm run dev` посилання на банку береться зі змінної `VITE_MONOBANK_JAR_URL` у `.env`, а підпис із `VITE_BARISTA_SIGNATURE`. Без першої кнопок чайових не буде.

**Тести й перевірки:**

```bash
npm test
npm run lint
npm run format:check
```

## Перевірка на телефоні в локальній мережі

1. Підключи телефон і комп'ютер до однієї Wi-Fi мережі.
2. Дізнайся IP комп'ютера: `ipconfig` у Windows (рядок IPv4) або `ip addr` у Linux.
3. Запусти `npm run dev` і відкрий на телефоні `http://<IP>:5173`.
4. Якщо сторінка не відкривається, дозволь Node.js у брандмауері для приватних мереж.

На `http://` замість «Поділитись у сторіз» буде «Зберегти картинку»: Web Share з файлами працює лише на HTTPS. Справжній шеринг перевіряй на задеплоєному домені.

Перевір на телефоні: гра однією рукою, обидві орієнтації, виріз екрана (safe-area), 320 px ширини, вібрація, звук (кнопка 🔇/🔊 у куті), `prefers-reduced-motion`.

## Налаштування

Усі параметри задаються змінними оточення (локально в `.env`, у Portainer в полі _Environment variables_ стеку).

| Змінна               | Призначення                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `MONOBANK_JAR_URL`   | Посилання на банку (`https://send.monobank.ua/jar/...`). Порожньо: кнопок чайових на сайті немає взагалі. Приймається лише `https://` |
| `SITE_URL`           | Постійна HTTPS-адреса сайту. Потрібна для Open Graph і для `npm run qr`                                                               |
| `BARISTA_SIGNATURE`  | Підпис на листочку і на картинці для сторіз. За замовчуванням `- Ваша бариста🦊 ☕`                                                   |
| `TELEGRAM_BOT_TOKEN` | Токен від @BotFather. Порожньо: бот вимкнено                                                                                          |
| `ADMIN_TELEGRAM_IDS` | Telegram ID адміністраторів через кому                                                                                                |
| `HOST_PORT`          | Лише для Docker: порт на сервері (за замовчуванням 3000)                                                                              |
| `IMAGE`              | Лише для Docker: повна назва образу, якщо не хочеш правити `docker-compose.yml`                                                       |
| `PORT`               | Порт сервера поза Docker (за замовчуванням 3000)                                                                                      |
| `TRUST_PROXY`        | `false`, якщо порт відкрито в інтернет напряму без reverse proxy (за замовчуванням довіряємо `X-Forwarded-*`)                         |
| `LOG_LEVEL`          | Рівень логів (за замовчуванням `info`)                                                                                                |
| `DB_PATH`            | Шлях до SQLite поза Docker (за замовчуванням `./data/phrases.db`)                                                                     |

**Секрети (токен бота) ніколи не кладуть у git.** `.env` вже в `.gitignore`.

## Посилання на банку Monobank

1. У застосунку monobank створи банку (для чайових зручно окрему) або відкрий наявну.
2. Натисни «Поділитися» і скопіюй посилання виду `https://send.monobank.ua/jar/XXXXXXXX`.
3. Встав його в `MONOBANK_JAR_URL`.

Кнопка відкриває банку в новій вкладці (`rel="noopener noreferrer"`) і не передає сторінці банку адресу цього сайту.

## Telegram-бот

Бот додає й вимикає подяки без перезавантаження сервісу. Зміни з'являються на сайті приблизно за хвилину (стільки живе кеш API).

### Створення бота

1. У Telegram відкрий [@BotFather](https://t.me/BotFather), надішли `/newbot`, обери назву й юзернейм.
2. Скопіюй токен у `TELEGRAM_BOT_TOKEN`.

### Як дізнатись свій Telegram ID

1. Запусти сервіс із порожнім `ADMIN_TELEGRAM_IDS`.
2. Напиши боту `/start`. Він відповість, що приватний, і покаже твій числовий ID.
3. Встав ID в `ADMIN_TELEGRAM_IDS` (кілька адміністраторів через кому) і перезапусти сервіс.

Усім, кого немає в списку, бот ввічливо відмовляє.

### Команди

| Команда                       | Що робить                                                 |
| ----------------------------- | --------------------------------------------------------- |
| повідомлення або `/add текст` | додає фразу                                               |
| `/list`                       | усі фрази по сторінках, ✅ активна, ⏸ вимкнена, ✨ золота |
| `/random`                     | показує випадкову фразу, як на листочку                   |
| `/off 12` · `/on 12`          | вимикає / вмикає фразу без видалення                      |
| `/gold 12`                    | робить фразу золотою (рідкісною) або знімає це            |
| `/del 12`                     | видаляє назавжди                                          |
| `/help`                       | довідка                                                   |

Фраза обмежена 300 символами. Зайві пробіли прибираються. Дублікати відсікаються без урахування регістру, розділових знаків і смайликів. Золоті фрази випадають приблизно в 5% листочків і мають особливе оформлення.

**Стартові фрази** з `src/phrases.json` імпортуються лише в порожню базу. Правка цього файлу після першого запуску на вже створену базу не впливає: далі керуй фразами ботом.

⚠️ Токен можна опитувати лише з одного місця. Якщо локально і на сервері працює бот з тим самим токеном, обидва отримуватимуть помилку 409. Для локальних тестів залиш токен порожнім або створи другого бота.

### 2. Nginx Proxy Manager

1. _Hosts_ → _Proxy Hosts_ → _Add Proxy Host_.
2. Domain Names: твій домен. Scheme: `http`. Forward Hostname / IP: IP сервера з Docker. Forward Port: значення `HOST_PORT` (за замовчуванням `3000`).
3. Увімкни _Block Common Exploits_. WebSockets не потрібні.
4. Вкладка _SSL_: новий сертифікат, _Force SSL_, _HTTP/2_.

Порт `HOST_PORT` лишається доступним у локальній мережі. Не прокидай його на роутері назовні: назовні має дивитись лише NPM на 80 і 443.

### Безпека

- Контейнер працює від непривілейованого користувача, з `read_only`, `cap_drop: ALL` і `no-new-privileges`. Для запису відкрито лише том `/data`.
- CSP без `unsafe-inline`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, HSTS на HTTPS-запитах.
- Rate limit лише на `/api` і щедрий (120 запитів на хвилину з IP), щоб не блокувати гостей, які сидять в одній мережі.
- Логи окремих запитів вимкнені: IP гостей не зберігаються.
- Фрази на сторінці виводяться через `textContent`, а значення з конфіга екрануються при підстановці в HTML.

## QR-код і друк

```bash
npm run qr                                   # бере SITE_URL з .env
npm run qr -- --url https://kava.example.com # або явно
```

Результат у папці `qr/`: `qr.svg` (вектор, для друкарні), `qr.png` і `print-a6.html`. Щоб отримати макет A6, відкрий його в Chrome, натисни Ctrl+P, обери папір A6, поля None, увімкни _Background graphics_, масштаб 100%, і збережи як PDF або друкуй. Параметри: `-- --no-url` прибирає адресу під QR, `-- --title "Свій заголовок"` змінює напис.

Щоб QR гарантовано зчитувався:

- QR має бути мінімум 4 см завширшки (у макеті близько 7 см). Правило: сторона приблизно в 10 разів менша за відстань сканування.
- Темне на світлому і вільне поле навколо (його вже закладено). Не інвертуй кольори й не клади логотип у центр.
- Матовий папір. Глянець і ламінування дають відблиски під світлом над стійкою.
- Перед друком усього тиражу роздрукуй одну копію і наскануй її з iPhone, Android (камера і Google Lens), у тьмяному світлі та з відстані 40–50 см.
- QR має вести на **постійний HTTPS-домен**: тоді перевипускати табличку не доведеться, навіть якщо змінюється сервер.

Іконка для iPhone і картинка для превʼю посилань (Open Graph) генеруються один раз:

```bash
npm run icons     # створює public/apple-touch-icon.png і public/og.png
```

Закоміть їх. Сервер сам додасть відповідні теги, якщо заданий `SITE_URL`.

## «Поділитись у сторіз»: як це працює

На листочку є кнопка, яка малює на canvas картинку 1080×1920 (формат сторіз): фон у стилі сторінки, листочок із текстом (автопідбір розміру шрифту, золота подяка зберігає золоте оформлення), підпис баристи і невеликий напис унизу. Картинка готується заздалегідь, одразу після появи листочка, щоб `navigator.share` викликався синхронно з жесту гостя: цього вимагає iOS Safari.

- Якщо браузер підтримує Web Share API з файлами (це потребує **HTTPS**), гість бачить системне меню, обирає Instagram і додає картинку в сторіз.
- Якщо ні, кнопка має підпис «Зберегти картинку» і завантажує PNG.
- **Прямого посилання, яке з веб-сторінки відкриває Instagram одразу в режимі Stories з готовою картинкою, немає** (вона можлива лише з нативного застосунку з Meta-інтеграцією). Тому ми не вигадуємо схем, що не працюють. Чи запропонує системне меню саме «Stories», залежить від телефона й версії Instagram. Якщо ні, гість зберігає картинку й додає її зі збережених.

## Налаштування вигляду та гри

| Що                                                  | Де                                           |
| --------------------------------------------------- | -------------------------------------------- |
| Кольори сторінки                                    | змінні в `:root`, `src/styles.css`           |
| Швидкість наливання, межі «ідеально» і «через край» | `src/game-logic.js`                          |
| Частота золотих фраз (за замовчуванням 5%)          | `RARE_CHANCE` у `src/phrases.js`             |
| Тексти підказок гри                                 | `TEXT` і `MESSAGES` у `src/game-logic.js`    |
| Стартові фрази                                      | `src/phrases.json` (лише для порожньої бази) |
| Ліміт довжини фрази (300)                           | `MAX_LEN` у `server/validate.js`             |

Картинка для сторіз використовує ті самі кольори: див. константи на початку `src/story.js`.

- [ ] `npm run icons` виконано, файли з `public/` закомічені

**Перевірка на телефонах**

- [ ] Гра працює однією рукою, подвійний тап не зумить, довге утримання не відкриває меню

**Друк**

- [ ] `npm run qr` для справжнього домену, без попереджень у консолі
- [ ] Тестова копія зчитується з iPhone й Android з різних відстаней

## Проблеми й рішення

| Симптом                                                        | Що робити                                                                                                             |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Monobank показує «Помилка підключення»                         | Перевір посилання на банку напряму в браузері. Переконайся, що в `MONOBANK_JAR_URL` справжнє посилання, а не заглушка |
| Portainer: `repository name must be lowercase`                 | У назві образу є великі літери. Використай `ghcr.io/<логін-малими>/<репозиторій>:latest`                              |
| Portainer: `denied` або `unauthorized` при завантаженні образу | Пакет приватний. Зроби його публічним або додай реєстр із токеном                                                     |
| `port is already allocated`                                    | Постав інший `HOST_PORT` і онови порт у NPM                                                                           |
| Бот мовчить або в логах 409                                    | Токен опитується ще десь (локальний запуск, інший контейнер)                                                          |
| Бот відповідає «приватний»                                     | Твого ID немає в `ADMIN_TELEGRAM_IDS` (бот показує його у відповіді)                                                  |
| Замість «Поділитись у сторіз» кнопка «Зберегти картинку»       | Нема HTTPS або браузер не підтримує Web Share з файлами: це очікувана поведінка                                       |
| Зміни фраз не видно на сайті                                   | Кеш API живе                                                                                                          |
